Intelligence artificielle

Assistant intégré

L'assistant IA vit dans le dossier. Il connaît son contexte — contacts, pièces, notes, chronologie, références — et vous aide à retrouver une information, rédiger un écrit ou extraire des données, sans quitter l'application.

Décrire la tâche en langage naturel

Formulez votre demande comme à un collaborateur. Des actions suggérées proposent des points de départ courants : « Extraire les dates clés du document », « Ajouter un contact avec ses informations », « Générer un document depuis un modèle ».

Assistant IA — saisie en langage naturel, actions suggérées, sélecteur de modèle et essai de pseudonymisation

Ce que l'assistant sait faire

  • retrouver une information précise dans les pièces et notes du dossier ;
  • rédiger un courrier ou un email à partir des données du dossier ;
  • extraire des dates, contacts ou références depuis un document ;
  • préparer une synthèse ou un résumé ;
  • déclencher des actions (créer un contact, générer un document…).

Modèle local ou API

Le sélecteur en bas du chat choisit le moteur. Un modèle local garantit qu'aucune donnée ne quitte votre machine ; une clé API externe apporte plus de puissance. L'option « Essai de pseudonymisation » remplace les identités par des marqueurs neutres avant l'envoi et les restaure dans la réponse.

Configuration. Le choix du modèle et la clé API se règlent dans Paramètres → Configuration IA. Vous pouvez démarrer sans IA et l'activer plus tard.
