Installation & mise en route

Ordicab s'installe en moins de deux minutes sur Mac et Windows. Aucune dépendance externe n'est requise pour commencer — l'application est autonome.

Version bêta. Ne pas utiliser avec des données réelles de clients. Des pertes de données ou comportements inattendus peuvent survenir.

Téléchargement

Rendez-vous sur la page des dernières versions GitHub et téléchargez le fichier correspondant à votre système :

  • Mac (Apple Silicon & Intel) — fichier .dmg
  • Windows (x64) — fichier .exe

Installation sur Mac

  1. Ouvrez le fichier .dmg téléchargé.
  2. Faites glisser l'icône Ordicab dans le dossier Applications.
  3. Au premier lancement, macOS peut afficher un avertissement de sécurité. Ouvrez Réglages système → Confidentialité & sécurité, puis cliquez sur Ouvrir quand même.
  4. L'application est signée et notariée par Apple — vous pouvez confirmer l'ouverture.

Installation sur Windows

  1. Exécutez le fichier .exe téléchargé.
  2. Si Windows affiche un avertissement SmartScreen, cliquez sur Informations complémentaires puis Exécuter quand même. L'application est signée via Azure Trusted Signing.
  3. L'installation se lance et crée un raccourci dans le menu Démarrer.

Premier lancement — configurer le cabinet

Au premier démarrage, Ordicab vous guide via un assistant de configuration :

  1. Choisissez l'emplacement de vos données. Ordicab vous demande de sélectionner ou créer un dossier racine sur votre machine. Vous pouvez le placer dans un dossier synchronisé (kDrive, iCloud, OneDrive…) pour un accès multi-poste automatique.
  2. Renseignez les informations du cabinet. Nom, adresse, téléphone, email — ces données alimenteront automatiquement vos modèles de documents et vos conventions.
  3. Définissez vos paramètres de facturation. Taux horaire par défaut, devise, mentions légales sur les factures.

Créer le premier dossier

  1. Dans la vue Dossiers, cliquez sur Nouveau dossier.
  2. Saisissez le nom du dossier (correspond à la référence principale de l'affaire).
  3. Choisissez le type de dossier et son statut initial.
  4. Le dossier est créé — vous pouvez commencer à y ajouter des contacts, des documents et des notes.
Données portables. Toutes les données Ordicab (métadonnées, notes, conventions, prestations…) sont stockées dans des fichiers JSON dans votre dossier racine. Vous pouvez les sauvegarder, les déplacer et les inspecter à tout moment.

Fonctionnement hors-ligne

Ordicab fonctionne intégralement sans connexion internet. La synchronisation cloud (si vous utilisez kDrive, iCloud, etc.) est gérée par votre service de stockage, pas par l'application. L'IA locale via Ollama fonctionne également hors-ligne une fois les modèles téléchargés.

Seules les fonctionnalités qui s'appuient sur une API distante (assistant via API, IA Cowork) nécessitent une connexion.
