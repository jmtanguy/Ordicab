Intelligence artificielle

IA Cowork Avancé

L'IA Cowork permet à un agent IA externe — Claude Code, Codex ou tout agent compatible — de travailler directement dans vos dossiers Ordicab. L'agent lit le contexte structuré du dossier et peut créer ou modifier des fichiers, toujours sous votre contrôle.

Principe de fonctionnement

Ordicab prépare un environnement de travail structuré que l'agent peut lire et exploiter. Cet environnement contient :

  • les informations du dossier (contacts, dates, références, notes) ;
  • les documents associés (texte extrait et indexé) ;
  • une inbox pour recevoir vos instructions et les productions de l'agent ;
  • des intents — des directives structurées qui cadrent les tâches confiées à l'agent et renforcent la robustesse des résultats.

L'agent lit l'inbox, exécute les tâches demandées, et dépose ses productions dans un répertoire dédié. Ordicab surveille ces dépôts et vous notifie des nouvelles productions disponibles.

Données transmises en clair. En mode Cowork, les données du dossier sont transmises à l'agent IA externe sans pseudonymisation. L'agent a accès au contexte complet du dossier. Utilisez ce mode uniquement si vous êtes à l'aise avec les conditions d'utilisation de l'agent choisi (Claude Code, Codex…).

Agents compatibles

  • Claude Code (Anthropic) — agent de référence, intégration native optimisée dans Ordicab.
  • Codex CLI (OpenAI) — agent en ligne de commande.
  • GitHub Copilot (mode agent dans VS Code).
  • Tout agent capable de lire et écrire des fichiers dans un répertoire local.

Ce que l'agent peut faire

  • Créer des documents — rédiger un courrier, une note, une convention à partir des données du dossier et les déposer directement dans le répertoire du dossier.
  • Analyser un dossier en profondeur — lire l'ensemble des pièces, identifier les points de droit, préparer un résumé structuré.
  • Extraire et organiser des données — identifier les contacts, dates, montants et références dans les documents et les structurer.
  • Alimenter les modèles de documents — compléter les champs d'un modèle avec les données du dossier.
  • Préparer des projets d'actes — rédiger une assignation, des conclusions, un mémoire à partir des faits et du contexte juridique.

Configurer l'IA Cowork

  1. Installez l'agent de votre choix (exemple : npm install -g @anthropic-ai/claude-code pour Claude Code).
  2. Dans Paramètres → IA → Cowork, sélectionnez l'agent et renseignez les paramètres de connexion.
  3. Ordicab crée automatiquement la structure de répertoires nécessaire dans votre dossier racine.
  4. Ouvrez un dossier, accédez à l'onglet Cowork, rédigez votre instruction et envoyez-la à l'inbox.
  5. Lancez l'agent sur votre machine (ou laissez Ordicab le lancer automatiquement si configuré).
  6. Les productions de l'agent apparaissent dans l'onglet Cowork une fois le travail terminé.

L'inbox et les intents

L'inbox est le canal de communication entre vous et l'agent. Chaque message que vous envoyez crée un fichier structuré que l'agent lira à son prochain démarrage.

Les intents sont des directives préformatées pour les tâches courantes : rédiger un courrier, extraire des contacts, préparer une facture, etc. Ils garantissent que l'agent produit un résultat dans le format attendu par Ordicab, et facilitent la réintégration des productions.

Validation toujours requise. L'agent dépose ses productions — Ordicab ne les intègre jamais automatiquement sans votre accord. Vous revoyez chaque production avant de la valider, la modifier ou la rejeter.
