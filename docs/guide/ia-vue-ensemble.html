Intelligence artificielle

IA — Vue d'ensemble

Ordicab intègre l'IA au travail réel du dossier, pas en marge. Elle exploite les contacts, documents, notes et informations structurées pour des tâches concrètes. Deux modes d'intégration couvrent tous les niveaux d'exigence — de la simplicité maximale à la confidentialité absolue.

Les traitements IA embarqués

Certains traitements fonctionnent localement, sans connexion, grâce aux modèles embarqués dans Ordicab :

  • Reconnaissance d'entités — identification automatique des noms, dates, adresses et références dans les documents.
  • Recherche sémantique — retrouvez une information dans un dossier par le sens, pas seulement par les mots-clés exacts.
  • Pseudonymisation — remplacement automatique des données personnelles avant envoi à une IA externe.

Ces traitements sont actifs en permanence dans l'application, sans configuration requise.

Les deux modes d'interaction IA

Mode En un mot Accès
Assistant intégré Chat IA dans le dossier, connecté à votre API cloud ou à un modèle local Ollama Paramètres → IA → Assistant
IA Cowork Collaboration directe avec un agent IA externe (Claude Code, Codex…) qui lit et écrit dans vos dossiers Paramètres → IA → Cowork

Pseudonymisation avant envoi

Quand vous utilisez l'assistant intégré via API, Ordicab peut remplacer automatiquement les données identifiantes avant de les transmettre au modèle : noms de personnes, adresses, emails, numéros de téléphone. L'IA travaille sur des alias cohérents sans accéder aux vraies identités.

La clé de correspondance reste sur votre machine. La pseudonymisation n'est pas réversible automatiquement dans le chat — elle protège les données transmises, mais le décodage des réponses est à votre charge. Elle est optionnelle et configurable par dossier.

Quel mode choisir ?
Commencez avec l'assistant intégré via API pour la simplicité et la puissance. Choisissez Ollama si la confidentialité absolue est prioritaire (données 100 % locales). Optez pour IA Cowork pour des tâches complexes nécessitant la création de documents ou une analyse approfondie.

Ce que l'IA peut faire dans Ordicab

Quelle que soit l'approche choisie, l'IA dans Ordicab peut intervenir sur :

  • retrouver une information précise dans un dossier (date, contact, référence…) ;
  • résumer des documents ou un ensemble de pièces ;
  • préparer un courrier, un projet d'email ou une note interne ;
  • extraire des contacts, dates et références depuis un document scanné ou importé ;
  • générer ou compléter des documents depuis les modèles du cabinet ;
  • accompagner l'organisation d'un dossier complexe ;
  • effectuer des recherches sémantiques dans vos dossiers.

Ordicab conserve toujours le contrôle. L'IA peut proposer, extraire, rédiger ou organiser — mais la validation, la structure et l'exécution des actions sur les données restent dans l'application.
